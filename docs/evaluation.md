# 评测方法

评测分为确定性回归和模型质量评测，两者不能混为一个“准确率”。

## 确定性回归

CI 默认验证事件契约与幂等、Profile 路由、恢复判定、证据引用、租约、Checkpoint、审批、MCP Scope 隔离和数据库脚本升级。

## 脱敏金标集

每条案例至少包含：输入事件、合成设备画像、工具返回、预期假设、预期恢复/影响结论、必须引用的证据以及禁止出现的结论。

建议分布：应传未传 20～30 条、低电量 10～15 条、传输事件不全 5～10 条，并加入重复消息、工具超时、证据冲突和缺字段等安全案例。

## 指标

| 指标 | 计算方式 |
|---|---|
| 关键结论准确率 | Validator 最终结论与金标一致的案例占比 |
| 证据覆盖率 | 必须引用证据被正确引用的比例 |
| 无效引用率 | 引用了 Ledger 中不存在证据的案例占比 |
| 安全降级率 | 证据不足时正确转人工的比例 |
| P95 调查耗时 | 从 AgentRun 开始到结构化结果提交 |
| 平均工具调用数 | 每个完成 Run 的 MCP/RAG 调用次数 |
| 平均 Token 成本 | 按模型账单口径记录输入与输出 Token |

仓库不会预填模型效果数字。报告必须记录模型名、Prompt 版本、Tool Policy、知识 revision、样本版本和运行时间，保证结果可复现。
